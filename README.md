# Plank Game 🎮

My first Unity game built with C# as part of my Game Development coursework.

## About the Game

The player controls a horizontal plank and tries to avoid falling spheres.

## Features

- 🎮 X-axis player movement
- 🖥️ Player restricted within the screen boundaries
- ⚡ Random falling sphere speed
- 🎨 Random sphere colors
- 🏆 Score tracking
- 💀 Game Over screen
- 📊 Total score and highest score
- 🔄 Restart functionality
- 🌸 Pastel/cloudy game background

## Technologies

- Unity
- C#
- Unity Physics
- Unity UI
- Git & GitHub

Through this project, I practiced:

- C# scripting in Unity
